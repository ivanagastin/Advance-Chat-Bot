# Advanced ChatterBot — Python AI Chatbot

An advanced, interactive, self-learning terminal chatbot powered by python's `ChatterBot` and machine learning.

---

## 🚀 Features

- **Self-learning Conversational AI:** Learns continuously from user interactions.
- **NLTK Pre-Trained Corpus:** Ready to discuss general topics, trivia, and humor out of the box.
- **Custom Conversational Data:** Trained on targeted tech/general greeting datasets.
- **Rich Terminal UI:** Beautiful ASCII banner, colored response prompts, and easy-to-use control commands.
- **Session History & Statistics:** Keep track of session exchanges and bot knowledge base stats.
- **Windows Terminal compatibility:** Built-in UTF-8 forcing for smooth emoji and box-drawing layout rendering on Windows.

---

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd "Advance Chatter Bot"
   ```

2. **Install Dependencies:**
   It is recommended to run the chatbot in a Python virtual environment:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Chatbot:**
   ```bash
   python chatbot.py
   ```

---

## 📋 Interactive Commands

Type any of the following commands directly into the prompt during your chat session:

| Command | Action |
|---|---|
| `help` | Display the detailed help menu with starters |
| `history` | Print the session conversation log |
| `clear` | Wipe the console screen |
| `about` | Learn about system architecture |
| `quit` | Exit the application safely (aliases: `exit`, `q`, `bye`) |
